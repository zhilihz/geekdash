GeekDash V1.051（1051本地版）
补充修正时间：2026-10-10 09:52:57（北京时间）；按用户要求保持1051。

运行
1. 将发布包完整解压到一个固定文件夹。
2. 用 Microsoft Edge 打开“GeekDash.html”（可设置HTML默认打开方式后双击）。无需安装Python、运行脚本或部署网页。
3. 首次使用时选择“打开项目数据库”，选择原数据库JSON并允许浏览器访问；以后在同一浏览器配置及固定文件夹中打开HTML，会记住上次文件。授权有效时直接读取并进入看板，不必重新选择备份。
4. 浏览器要求重新授权时仍显示上次看板，点击“授权上次数据库”即可继续使用原文件；修改未写回时点击“授权并保存到原文件”，也可“另存当前数据”。修改会保留在本机，待保存状态变为“已自动保存”后才表示写入数据库文件。
5. 如需切换文件，在首页选择“更换数据库”；未写回修改需先保存或另存。进入管理模式编辑后，仍需检查首页数据库保存状态。
6. 清除浏览器数据、换浏览器或移动HTML文件夹时可能需要首次重新选择原文件；从旧HTTP入口改为直接打开HTML，也需要选择原JSON一次。首次选择/授权由使用者完成，程序不能绕过浏览器权限。

旧版数据兼容
V1.049和V1.050使用相同的全数据JSON格式。1051可直接打开这两版导出的全数据备份JSON或1050数据库文件。
1049若数据仅在旧浏览器内，请先在1049中导出“全数据备份JSON”，然后在1051首页打开此文件。同一浏览器还能看到旧缓存时，也可选择“将当前浏览器数据存为数据库”。
新增简介和专用状态历史在旧项目中按空值/现有原文处理；原工程师角色、风险、变更、延期、阶段、历史和项目扩展字段保留。旧文件不需手工改字段。
打开文件后的新修改会回写所选择的文件；如需保留旧版本原始副本，先复制数据库文件，打开副本试用。此包不包含用户业务数据库。

本版修改
1. 项目详情标题随滚动保持可见，日期时钟正常滚出视口。
2. 风险预警与需求变更可编辑，创建时间保留，修改前后内容进入历史。
3. 未结案项目按预计结案日期自动判断延期：今天晚于预计日期才算延期，当天不算；未填日期显示未定；已结案不计当前延期。延期记录保留，新目标日期不替代预计结案日期。
4. 所有看板的“项目最新状态”区域默认折叠，可展开；重新进入或刷新后收起。
5. 每个项目增加简介，详情输入，卡片展示。卡片移除变更次数、负责人、项目经理、周期与市场预期，仍可在详情查看。
6. 状态描述只更新最新内容，上方折叠展示完整描述历史；旧版完整更新原文另行保留。
7. 状态描述输入@检索基础工程师，例如@李可选择李雪；无候选时输入完整姓名并回车，仅保留@姓名文字，不会自动新增到基础工程师库；保存状态也不自动新增。已有工程师及角色保留。候选选中后自动加空格分隔姓名。
8. 状态简要增加“负责人”显示列与筛选。只取最新已保存状态描述的@姓名，多人去重，不自动加入项目负责人；字段开关同步控制导出。
9. 阶段完成后可“回退到此阶段”，确认后该阶段及后续恢复未完成，原评述、完成日期留在更新历史，排期保留。阶段页及流程图均有入口。
10. 已结案项目可撤销结案。1051的中途结案恢复结案前状态；旧版未存原状态时，在确认框中选择恢复状态，原结案理由留在历史。
11. 首页不再单独展示风险预警和需求变更专区，相关开关同步移除；修改内容仍记录在项目最新状态及详情历史。
12. 基本信息直接把项目状态改为已结案，按100%整体结案；仅在项目阶段点击中途结案时保留当时进度。原阶段日期和评述保留，撤销结案后恢复阶段进度。旧版有中途结案理由的项目继续按原阶段进度显示。
13. 双击HTML直接运行，首次连接数据库后记住同一文件，浏览器重启后恢复读取；未写回修改保留，原文件授权及另存入口可在正常看板操作。
