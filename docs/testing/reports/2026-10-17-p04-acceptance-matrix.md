# P04逐行为验收核对表

本表保留2026-10-17建立的验收编号；现行PRD插入或调整行为后，按行为名称对应，不再把旧编号当作当前表格的第几行。后续新增行为使用同节“补”编号，旧行不重排。这里只维护验证状态与证据，不复制业务规则；源规则以[PRD](../../product/PRD.md)为准。

本表是行为覆盖及证据入口，不代替发布记录。通过行区分实际运行、共用机制复用与入口代码核对；应用无法观察的浏览器/系统结果另列未测边界，不能混写成产品已经完成该外部动作。共用结果必须落实到适用页面/写入范围，单页通过不能支持无关页面通过。

证据产生基线：codex/p04-plan-reassessment，f07450e加当时工作区成果。2026-10-19已有成果固定为3794a38并推送部署，见[发布报告](2026-10-19-p04-candidate-release.md)；本表各行保留原测试时点，不因发布冒烟自动升级为全部通过，当时完整阶段尚未验收。

2026-10-20适用性更新：本表原行号和多数证据保留10月17～19日时点，当前行为以现行PRD及[操作简化报告](2026-10-20-operation-simplification.md)、[原任务返回与草稿接续报告](2026-10-20-work-recovery.md)为准。旧“基本区静态初态/点击修改”“周检查截止/规则配置”“普通纠错必须原因和预览”等表述已被最新确认替代，不能作为当前待补功能，也不能根据旧状态数量推算当前完成率。2026-10-21继续按既有结果文件、实际断言及原生记录对齐；退役行保留旧编号并标明不适用，不能依据状态数量推算完成率。

验收方法以testing.md“按PRD行为结果验收”为准：专有前置逐项覆盖，原生浏览器核对代表性正常、拒绝、冲突、未知及恢复；相同机制可引用已有贯通证据。没有逐组合重复原生操作本身不构成缺口，缺的是该结果实际数据/反馈/恢复证据时才保留未通过。

早期原生证据在[设计及页面证据目录](../../evidence/p04-01-design/)，本轮证据在[10月21日验收目录](../../evidence/2026-10-21-p04-acceptance/)和[恢复目录](../../evidence/2026-10-21-p04-recovery/)。早期范围保存回归见[scoped-ui结果](../../evidence/2026-10-16-p04-scoped-ui.json)，本轮受影响回归与原生结果见对应报告。部分已验证仍表示行内有明确专有分支未核验，不能作为整行通过。

2026-10-19证据收敛：本次只核对既有结果文件、对应脚本实际断言和原生记录，没有重新执行测试。历史版本的证据明确标注；有当前深层及代表性页面证据的结果按已有验收方法复用，专有提示或恢复缺口继续保留，不能把状态数量当功能实现比例。
