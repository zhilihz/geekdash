## 5. 程序复现入口

以下脚本均以合成数据运行。需要在已配置好的独立测试容器中设置 `GEEKDASH_MIGRATION_PROBE=1` 和实际隔离库的 `GEEKDASH_MIGRATION_PROBE_SERVER_UUID`；脚本会检查目标实例。不要填用户数据库的 UUID 来绕过隔离边界。数据库演练串行执行。

```text
node scripts/verify-import-repair.mjs
node scripts/verify-panel-task-repair.mjs
node scripts/verify-project-recovery.mjs
node scripts/verify-import-takeover-recovery.mjs
node scripts/verify-import-workbench.mjs
node scripts/verify-write-recovery.mjs
```

前端模型还需要 `GEEKDASH_JSDOM_PATH` 指向测试工具的 JSDOM `api.js`，该工具不进入运行镜像。结构升级演练 `node scripts/verify-project-name-reservation-migration.mjs` 另需 `GEEKDASH_NAME_MIGRATION_PROBE=1`，会模拟 0015 结构及中断，必须独占隔离实例，不与其他测试／应用并行。

语法复核可逐文件执行 `node --check <上述旧脚本路径>`。编译入口为 `node node_modules/typescript/bin/tsc -p tsconfig.server.json --noEmit` 和 `node node_modules/typescript/bin/tsc -p tsconfig.web.json --noEmit`；这些命令不会证明真实页面已通过。
