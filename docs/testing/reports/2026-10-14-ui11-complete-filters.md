# E04-UI11 完整筛选设计核查

日期：2026-10-14。范围是原 Figma 的 W01 卡片首页、W02 驾驶舱、W31 筛选无结果页。交互权威归 [PRD 首页完整筛选](../../product/PRD.md#首页完整筛选)，本报告记录实际核查结果。

## 来源与产物

对照 `GeekDash1051/GeekDash.html` 的 `FILTER_DIMS`（2282～2299 行）、选项取值（1832～1863 行）及折叠实现（2338～2355 行）。原版是 13 个维度，负责人包括硬件、软件和项目经理。原版整体折叠没有已选摘要；本轮按用户要求保留全部维度，并补足折叠后的可见反馈。

在[原 Figma 文件](https://www.figma.com/design/leQy2Be9GaTXPvZeooQuIF?node-id=144-3499)的页面 `142:3499` 原位修改，未新增页面或平行设计稿。保留 36 个业务画面与目录；仅替换三处不完整筛选区域。使用既有按钮、字体和主题变量，恢复原版逐行胶囊选项。

| 核查 | 结果 |
| --- | --- |
| 三处完整筛选 | 各包含相同 13 个维度，顺序与原版定义一致 |
| 原型选择反馈 | 单项选择、再次点击取消、替换选择、选“全部”、摘要逐项取消、清空与折叠保留，共 66 项存储配置推演通过 |
| 默认状态 | 29 个本轮原型变量恢复为整体折叠、无已选条件；无选择时摘要行隐藏 |
| 视觉观察 | 已查看展开区、折叠后两个已选条件、W01 默认首页、W02 驾驶舱、W31 无结果页共 5 张截图；修正了行高和宽度后复核 |
| 展示一致性 | 三处共用筛选变量；W31 两处清空入口均清除条件并回 W01 |
