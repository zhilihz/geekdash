## 工程基线

具体选型已收敛于[技术栈基线](../architecture/technology-stack.md)：Node.js 24、Fastify 5、mysql2、MySQL 8.4、Vite 多页面构建、Vitest 与 Playwright；首版不部署 Redis。五点路线为用户明确选择，具体库为助手据此选定的实施基线，尚未构建验证。此前提出的 Vue 单页应用和 ORM 方案不纳入首版。
