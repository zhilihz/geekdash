## GD-AUTH-20261019-001：凭据交付必须验证实际登录

- 快速处理：对已经首次改密的账号，读取受控文件的当前密码，通过实际登录页登录，再核对目标权限；不要仅用账号存在、角色或业务账号冒烟结果证明维护账号可用。
- 本次事实：2026-10-19公网 `maint01` 使用受控 `currentPassword` 成功登录；用户原登录框的值与当前密码及原临时密码均不相同，仅比较布尔值，未输出内容。尚无证据说明差异是怎样产生的，不能归因为账号停用或服务端错误。
- 处理与验证：重新提供仓库外单账号凭据文件，只包含当前有效密码；Edge新登录后进入资料与设置，客户资料修改表单及保存按钮可用，随后取消修改。未重置密码、未保存业务资料。系统真相记录本次验证范围。
- 防复发：交付前按账号实际验证；网页改密不会自动同步本地交付文件，旧临时密码不能沿用。密码、哈希、会话和受控文件正文不进入项目记录。

## GD-WEB-20261016-001：草稿同步比较规范化内容

- 范围：P04个人底稿客户端与MySQL JSON回读；2026-10-16，候选0004独立实例。
- 现象：`verify-scoped-ui.mjs`超时于“基本区保存并新读”，日志反复出现草稿写入200，正式PATCH未开始。

- 防复发：任何自动保存响应比较都按语义内容处理，不依赖数据库JSON键顺序；故障回归保留在页面链路脚本。
